# 03_balancing_selection

Compare balancing selection signals using inferred pairwise time to the most common ancestor (TMRCA) between two datasets.

## Scripts

- `all_chr_mask_plot.py` — Plot the manhattan plot of pairwise TMRCAs for all chromosomes.
- `create_all_chr_panels` — Scan for gene hits and create the panels for whole-genome manhattan plot.
- `allele_evolve_sim.py` — Compute the probability of observing an allele frequency higher than threshold, for a given setting.
- `hla_plot_integrate.py` — Plot the pairwise TMRCAs for the HLA regions, for 3 ARG inference methods and 2 datasets.
- `create_hla_panels.py` — Scan for gene hits and create the panels for HLA plot.
- `heatmap.py` — Generate the heatmaps between 2 datasets, for HLA-genes region and the rest region.
