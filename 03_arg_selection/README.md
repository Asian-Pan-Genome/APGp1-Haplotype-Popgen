# ARG Inference and Selection Analyses

This directory contains scripts for ancestral recombination graph (ARG) inference and ARG-based selection analyses using both assembly-derived and short-read-derived SNP datasets.

## Directory Structure

```text
03_arg_selection/
├── 01_arg_construction/      # ARG inference and dating
├── 02_positive_selection/    # ARG-based positive selection scans
└── 03_balancing_selection/   # Balancing selection analyses in the MHC region

## Overview

### 1. ARG Construction

ARGs were inferred from assembly-derived and short-read-derived SNP datasets using `tsinfer` and `tsdate`. Population recombination maps generated by `pyrho` and ancestral alleles from an eight-way great ape alignment were incorporated during inference. For the HLA region, additional ARGs were reconstructed using `SINGER` and `Relate`.

#### Variant Filtering

Prior to ARG inference:

- All non-SNP variants were excluded
- Multi-allelic SNPs and sites with unknown ancestral states:
  - retained for `tsinfer`
  - removed for `SINGER` and `Relate`
- Missing genotypes:
  - partially retained for `tsinfer`
  - removed for `SINGER` and `Relate`

For assembly-derived datasets:

- Samples with ≥5% missingness per autosome were removed
- Variants with >10% missingness were excluded

Scripts are available in:

```text
01_arg_construction/
```

---

### 2. ARG-Based Positive Selection Scan

Positive selection scans were performed using a modified implementation of the Speidel et al. (2019) statistic on `tskit` tree sequences. The implementation supports polytomies in local genealogies and multiple mutation mappings per SNP.

Simulation benchmarking included:

- Positive selection models using `SLiM`
- Neutral demographic simulations using `stdpopsim` and `msprime`

Filtering criteria for candidate signals:

1. SNP/tree located within 35 kb of a large SNP gap (≥10 kb)
2. Tree mutation mapping ratio ≥2.5

Scripts are available in:

```text
02_positive_selection/
```

---

### 3. Balancing Selection in the MHC Region

Balancing selection analyses were performed using ARGs inferred in the HLA region.

For each non-overlapping 1-kb window:

- Average pairwise TMRCA was calculated
- Generation time was assumed to be 25 years

Regions with TMRCA >12 Mya were considered putative balancing selection signals and intersected with protein-coding genes.

Scripts are available in:

```text
03_balancing_selection/
```
