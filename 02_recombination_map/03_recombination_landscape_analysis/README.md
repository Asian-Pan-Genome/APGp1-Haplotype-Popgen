# 03_recombination_landscape_analysis

Downstream analyses of CHA recombination landscapes.

## Notebooks

- `01_correlation.ipynb` — Spearman correlation of recombination rates across populations (CHA vs CHB/CHS/etc.) across different scales.
- `02_hotspot_overlap.ipynb` — identify recombination hotspots per population and compute pairwise hotpost overlap.
- `03_prdm_hotspot_enrichment.ipynb` — test enrichment of PRDM9 binding motifs (Concensus / B-allele-preferred) in recombination hotspots.
- `04_sd_divergence.ipynb` — analyze recombination rate difference between pairs of segmental duplication.
- `05_inversion.ipynb` — characterize recombination suppression in common inversions in CHA.
