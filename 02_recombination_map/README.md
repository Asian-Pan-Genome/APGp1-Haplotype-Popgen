# Fine-Scale Recombination Landscape Analysis in APGp1-CHA

This repository contains scripts and workflows for fine-scale recombination rate inference, PRDM9 binding-site prediction, hotspot analysis, and recombination landscape characterization in the APGp1-CHA population.

---

## Overview

This project includes:

- Fine-scale recombination map inference using Pyrho
- Demographic inference using SMC++
- PRDM9 binding-site prediction with FIMO
- Comparison with published CHM13-native 1kGP recombination maps
- Recombination analyses in segmental duplications (SDs) and inversions
- Recombination rate decay profiling around PRDM9 motifs

# Methods

## 1. Fine-Scale Recombination Rate Estimation

Fine-scale recombination rates along 22 autosomes were inferred for 99 unrelated APGp1-CHA samples using Pyrho.

Both SR-derived and pangenome-derived biallelic SNP callsets were analyzed independently.

Population demographic history between 100 and 5 × 10^5 generations ago was inferred using SMC++.

### Key Parameters

| Parameter | Value |
|---|---|
| Inference mode | Unphased |
| Block penalty | 35 |
| Window size | 60 |
| Initial haplotype size | 300 |
| Downsampled haplotypes | 198 |

### Notes

- Mutation rate was set to `1.25 × 10^-8`
- Genomic segments exceeding 100 kb without called variants were treated as missing
- Lookup tables were generated using the Moran approximation

## 3. Recombination Landscape Comparison with CHM13-native 1kGP Maps

Recombination landscapes inferred in this study were compared with published CHM13-native 1kGP recombination maps.

### Analyses Included

- Spearman correlation of recombination rates
- Random sampling of 1,000 positions per autosome
- Filtering inaccessible positions and extreme outliers
- Hotspot identification
- PRDM9 motif enrichment analysis

### Hotspot Definition

Following Halldorsson et al. (2019), hotspots were defined as regions with recombination rates exceeding 10× the chromosome-wide average.

To minimize SNP-density-dependent batch effects:

- Fixed non-overlapping 1 kb windows were used
- A window was classified as a hotspot if any span exceeded the threshold

### Permutation Analysis

To assess hotspot enrichment at PRDM9 motifs:

- 1,000 shuffled replicates were generated
- Block-wise shuffling was performed using 100 kb blocks to preserve local motif density

## 4. Recombination Rates in Segmental Duplications and Inversions

### Segmental Duplications (SDs)

Genome-wide SD annotations were generated by combining:

- CHM13v2.0 SD annotations
- Fixed SDs identified using panSD

Pairwise SD alignments were generated using MAFFT.

Sequence divergence was estimated using:

- Pairwise proportional distance
- Jukes-Cantor correction

### Inversions

Inversion callsets were integrated from:

- PAV
- SVIM-asm
- LSGvar

Analyses focused on inversions satisfying:

- Length ≥ 1 kb
- MAF ≥ 0.1 in APGp1-CHA

### Baseline Comparisons

Inversion-associated recombination rates were compared against:

1. Chromosome-wide average recombination rates
2. Length-matched random control regions sampled from accessible genomic regions

## 5. Recombination Rate Decay Around PRDM9 Binding Motifs

Two classes of PRDM9 motifs were analyzed:

| Motif Type | Description |
|---|---|
| Human1–Human6 | PRDM9 A-type motifs |
| Human7 | PRDM9-B preferred motif |

### Analysis Strategy

- Only autosomal motifs within SR-accessible regions were retained
- Motif midpoint was defined as the center coordinate
- Symmetric windows of ±8 kb were analyzed
- Recombination rates were sampled every 50 bp

### Statistical Analysis

- Rates were normalized by genome-wide average recombination rate
- Mean recombination profiles were aggregated across motif instances
- 95% confidence intervals were calculated as:

```text
mean ± 1.96 × s.e.m.
```
